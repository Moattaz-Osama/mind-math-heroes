# Mind Math Heroes

A free, single-file web app that turns mental-math practice into a game for kids — pick a hero, choose a mode, and answer addition/subtraction problems to earn coins, unlock gear, and level up.

Bilingual out of the box: **English** and **Arabic** (with full right-to-left layout), switchable at any time.

## Play it

Open `index.html` in any modern browser — no install, no build step, no server. Progress is saved automatically in the browser's local storage, so it picks up where you left off next time.

## Modes

- **Hero Journey** — story-driven progression through levels, chapter by chapter, with difficulty that ramps as skills improve.
- **Speed Dash** — a quick, timed challenge to answer as many problems correctly as possible before the clock runs out.
- **Daily Mission** — one short, focused practice session per day.
- **Free Play** — untimed practice, no pressure.
- **Abacus Lab** — say or enter a number and watch it come alive on an interactive soroban (abacus), a hands-on intro to place value.
- **Weak Spots** — automatically surfaces and drills the specific facts a child struggles with most.

## Motivation & progression

- Earn coins for correct answers, spendable in a **Hero Shop** on cosmetic gear (cuffs, capes, crowns, and more) for your chosen character — with a second-tier **upgrade** path for gear you already own.
- Unlock **achievements** and **certificates** as milestones are hit.
- A **Skill Map** lays out the full learning path as a level-by-level board to track progress at a glance.
- A built-in **parent gate** protects settings and higher difficulty tiers from little hands.

## Teacher / Presenter Mode

A dedicated screen for classroom use: pick a level, flash a problem on screen, reveal the answer on demand, toggle the abacus for a visual walkthrough, use read-aloud, and keep a running class tally of correct answers vs. retries — all from one screen built for projecting.

## Accessibility & design

- Full English/Arabic localization, including mirrored layout for RTL.
- Keyboard-operable abacus beads and touch targets sized for kids on mobile.
- Light and dark-friendly, responsive from small phones up.

## Tech

Plain HTML, CSS, and JavaScript in a single file — no framework, no build tooling, no external dependencies. State lives in `localStorage`; all artwork is hand-drawn inline SVG.
